# Student Management System - SQL

## 📌 Project Overview

A Student Management System built using MySQL to manage
student information, courses, enrollments, and marks.

This project was created to practice SQL concepts and
database operations using a real-world style database.

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench
- SQL
- Git
- GitHub

## 🗃️ Database Structure

**Database Name:** `CON_Student_Management`

The database contains the following tables:

- `students` — stores student information
- `courses` — stores course and program information
- `enrollments` — stores student course enrollments
- `marks` — stores subject-wise marks

### Project Data

- 5 Students
- 5 Courses
- 5 Enrollments
- 15 Marks Records

- Manage student information
